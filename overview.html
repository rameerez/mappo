A world map you drop into a page

One custom element. A dot field or real coastlines, flat or as a leaning globe you can spin, with country borders, a graticule, and your own HTML pinned to places on it. No build step, no API key, no network calls — the whole planet ships in the file.

<script type="module" src="https://unpkg.com/mappo/dist/all.js"></script>

<mappo-world mode="globe"
  figure="solid outline" figure-source="vector"></mappo-world>

That is the entire integration. The core is 22.1 KB gzipped with the whole Earth inside, zero dependencies, MIT. The globe, real coastlines, the other projections and other worlds are opt-in modules — or take everything at once in all.js, 60 KB. Any world you can describe as a function is a body too.

One element — four very different worlds

The dot field, lying down

The look mappo is named for: land as dots at whatever resolution you ask for, a surface wave that reads as height under tilt, places by name.

<mappo-world tilt="34" animation="wave"
  places="London, Lagos, Singapore">

Real coastlines, and borders

The Natural Earth outline instead of the grid — smooth at any size, with country borders a raster could never express, over a dotted sea.

<mappo-world figure="solid outline"
  figure-source="vector" borders
  ground-color="#dfe6da">

A globe you can grab

The same dots on a canvas sphere: drag to spin, flick for momentum, release and it keeps its heading. Hover and click still reach every dot.

<mappo-world mode="globe" tilt="24"
  rotate-speed="7" ground-color="#dfe6da">

Pointing at one place

A globe that faces a country, drops a real map pin on it and lights up the whole territory. You bring the rings; mappo ships no boundary data on purpose.

<mappo-world focus="46.5,2.35" rotate-speed="0"
  marker-shape="pin" highlight-polygon="[…]">

Every one of these is live and copyable — along with the leaning globe above, a day/night terminator computed from your own clock, and an Earth in orbit — in the demo gallery.

Install — pick the line that matches your stack

A script tag

The 22.0 KB core; the element registers itself. For the globe, real coastlines and the other projections, load all.js instead.

<script type="module"
  src="https://unpkg.com/mappo"></script>

<!-- or everything, one file -->
<script type="module"
  src="https://unpkg.com/mappo@0.7.0/dist/all.js"></script>

An import map

Modules find the core by the URL next to them, so map the core to its full path.

<script type="importmap">
{ "imports": {
  "mappo":       "https://unpkg.com/mappo@0.7.0/dist/mappo.js",
  "mappo/globe": "https://unpkg.com/mappo@0.7.0/dist/globe.js" } }
</script>
<script type="module">import "mappo"; import "mappo/globe"</script>

npm

Though the point is that you don't need a bundler. Import only what the page uses.

npm install mappo

import "mappo";              // 22.1 KB: the flat map, the whole Earth
import "mappo/globe";        // + the globe
import "mappo/projections";  // + Equal Earth, the poles, d3-geo

Why this one

Two levels of detail of the same world

A 3.6 KB run-length land mask (Natural Earth, public domain) generates the dot grid at any resolution — resolution is a slider, not a redesign. Ask for figure-source="vector" instead and you get the real coastline, smooth at any size, plus borders that follow rivers.

The same options on both renderers

The flat map is SVG and the globe is canvas, because each is right for its job — but figure, borders, ground-color and the rest are one vocabulary across both. Switching mode keeps your styling.

Your DOM, on a sphere

Put an <a data-lat data-lon> inside the element and mappo positions it every frame, publishing how far it has turned away as --mappo-depth and marking it data-mappo-behind at the horizon. Labels fade and hide with plain CSS — mappo never dictates how they look.

Places by name, on any world

Every body carries its own gazetteer: places="Nairobi, Seoul" on Earth (~160 cities), places="Apollo 11, Shackleton" on the Moon, places="Curiosity" on Mars. Coordinates snap to the nearest figure dot. Or skip the gazetteer entirely with markers="Name@lat,lon".

Any world, one interface

Earth ships in the core; the Moon and Mars are opt-in packs of 7–10 KB. A body is a small object — figure(lat, lon), optional outlines, borders and places — so an invented planet for a game is a function, and registerBody() gives it a <mappo-yourworld> tag.

Real elements, your CSS

The flat map is light DOM: every dot hoverable, every marker focusable, everything restylable from your stylesheet. Colours accept var(--token) and are re-resolved on a theme flip, so a dark-mode toggle repaints the map for free. Events bubble as mappo:placeclick and friends in both modes — the globe re-earns them with canvas hit-testing.

Zero everything

No dependencies, no build step, no network calls, no API keys, no tracking. One ES module — script tag, import map, or npm — with differential updates, adaptive debouncing tuned to your machine's real frame cost, and a budgeted perf harness in the repo. prefers-reduced-motion respected. MIT.

Every attribute

The world

attributewhat it does
modeflat (default) · globe — a rotating, grabbable canvas sphere. Drag to spin, flick for momentum.
colsResolution: dots across the full longitude span. Auto: 120 flat · 170 globe; hard max 260.
bodyWhich world: earth (default, in the bundle) or any registered body — moon, mars, your own. Every body also has its own tag: <mappo-moon>.
lat-min / lat-maxThe latitude band drawn. Defaults to the body's own framing: -58…84 on Earth (Antarctica and the arctic emptiness cut), pole to pole on the Moon and Mars.
backgroundA uniform fill behind everything: the rect on the flat map, the disc on the globe.
ground-colorEverything that is not figure — the ocean, the highlands — as filler dots in their own shade. Draws under any figure style, so solid continents can still sit on a dotted sea.
interactive / cursorTurn pointer behaviour off for pure decoration; set the cursor over the map.
max-dprCaps the canvas backing store (default 2). 3× devices buy no visible detail on a dot field and pay full fill-rate for it.
layer-bleedHow far layers (addLayer, mappo/links) may draw past the map's box, as a fraction of it on every side (default 0), so an arc's apex above the limb is not cut at the element's edge.

The figure

Every map draws a figure on a ground. On Earth the figure is land and the ground is ocean; on the Moon, maria on highlands; on Mars, lowlands on highlands; on your own world, whatever you say. Every option that styles the figure starts with figure-.

attributewhat it does
figureA space-separated token list, so it reads the way you would say it: dots (default) · solid · outline · solid outline.
figure-sourcegrid — contours traced from the body on the dot grid: blocky by design, follows cols, costs nothing extra. vector — the body's own outlines (Natural Earth on Earth), smooth at any size.
figure-colorThe figure's colour: the dots, or the fill. Any colour, including var(--token).
figure-stroke / figure-stroke-widthThe edge — the coastline on Earth. Defaults to figure-color.
bordersRegion boundaries where the body has them: country borders on Earth. Vector data, so they work under any figure style; a 512×256 raster cannot express a border that follows a river.
borders-color / -width / -opacityDefault to the edge colour at 0.5 and 0.55.

Dots

attributewhat it does
dot-shapecircle · square · triangle · tile, a square lying on the surface (a sliver at the globe's limb, a square on the flat map) · a custom SVG path (24×24 units).
dot-sizeFraction of a grid cell the dot fills (default 0.55).
dot-hover-color / -scaleHover colour auto-derives as a contrast-aware shade of figure-color — darker for light dots, lighter for dark. Override either.

The globe

attributewhat it does
rotate-speedDegrees per second. 0 parks it.
rollThe lean, in the plane of the screen. This is what makes a globe look photographed rather than diagrammed.
tiltAxial tilt on the globe; degrees of rotateX on the flat map.
focus"lat,lon" the globe starts facing — with rotate-speed="0" it holds there.
globe-ringA hairline halo at the limb. Off by default.
graticuleThe meridian and parallel grid.
meridians / parallelsHow many of each (12 and 11). The equator is drawn separately, so it can carry its own weight.
graticule-color / -opacityDefault to figure-color at 0.28.
equator-color / -opacityDefault to the graticule at 0.36 — a touch above its neighbours, never a stripe.
graticule-widthLine width, CSS px on the globe (0.5 is one device pixel on a 2× screen); a multiplier of the flat map's hairline.
distanceA perspective camera that many body radii from the centre. Default Infinity, the orthographic view; 2.4 is a globe seen from close by — near side larger, far side smaller, the limb on the same disc.
fog"near far" in radii from the centre plane. Set, the globe is glass: the far hemisphere shows through and everything fades from opaque at near to gone at far.
fog-colorThe fog's colour. Unset, the fog fades to transparent; set, everything in it is drawn in its own colour mixed toward this one, as a WebGL fog blends.
distributiongrid (the lat/lon grid) · uniform, a Fibonacci lattice with equal area per dot and no bunching at the poles.

Markers and overlays

attributewhat it does
placesComma-separated names from the body's gazetteer: "Nairobi, Seoul" on Earth, "Apollo 11" on the Moon.
markersCoordinates without the gazetteer: "Name@lat,lon;…" — same pipeline and events as places.
marker-shapecircle · square · triangle · pin, the map-pin silhouette, anchored at its tip.
marker-color / -scale / -cursorAny colour; size relative to a dot; the cursor over a marker.
marker-pulseA radar ping: an expanding, fading ring.
overlaysPosition host children carrying data-lat/data-lon over the map (globe). On by default; each gets --mappo-depth and data-mappo-behind.
highlight-polygon / -colorJSON rings of [lat, lon] — every figure dot inside draws in the highlight colour. You supply the shape; the point-in-polygon test runs once per geometry build, never per frame.

Motion and the hero look

attributewhat it does
tilt / rotate / perspectiveThe lying-down hero look: degrees of rotateX and rotateZ, perspective in px.
animationnone · wave, a thin rolling crest · noise, two-octave perlin · ripple · sweep, a sonar pass · sparkle.
animation-period / -height / -widthSeconds per cycle · crest height in cells · crest thinness as a fraction of the cycle.
