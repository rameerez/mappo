Beautiful web maps

A world map as a web component. Dots or coastlines, flat or a rotating globe, Earth or the Moon or Mars — in 22 KB, with no dependencies.

npm i mappo
See the demos GitHub

22 KB, everything in

The core carries the engine, Earth's land mask and its gazetteer. The globe, projections, vector coastlines, arcs and other worlds are opt-in modules you import only if you use them.

One element

Fifty attributes, no build step, no bundler. Drop <mappo-world> on a page and style it with CSS variables — a theme flip repaints every map without a line of JS.

Not only Earth

A body answers whether a coordinate is inside or outside. The Moon is 9.5 KB, Mars 6.9 KB, and the renderer never learns which one it is drawing.
